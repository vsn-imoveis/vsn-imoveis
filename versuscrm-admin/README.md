# Painel administrativo original do VersusCRM

Aplicação recuperada do repositório original `vsn-imoveis/versuscrm`, branch `main`.

Esta cópia fica isolada nesta pasta para não substituir o site VSN Imóveis nem suas rotas existentes.

## Arquivos
- `app/page.tsx`: painel administrativo original.
- `app/layout.tsx` e `app/globals.css`: layout e estilos originais.
- `package.json` e `pnpm-lock.yaml`: dependências originais.
- Arquivos de configuração do Next.js e TypeScript.

## Execução independente
Dentro desta pasta, instale as dependências com `pnpm install` e execute `pnpm dev`.

As rotas de servidor administrativas do projeto original ainda precisam ser incorporadas para habilitar provisionamento, gerenciamento de acesso e decisões de solicitações.
